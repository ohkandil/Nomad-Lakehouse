Configuration Help

This configuration panel manages the .env file used by the Nomad Lakehouse stack.

  • MinIO API Port - Port for S3 API operations (default: 9000)
  • MinIO Console Port - Port for MinIO web console (default: 9001)
  • PostgreSQL Port - Port for PostgreSQL database (default: 5432)
  • Dashboard Host - Bind address for the dashboard (default: 127.0.0.1)
  • Dashboard Port - Port for the dashboard server (default: 8088)
  • Warehouse Bucket - MinIO bucket for Iceberg tables (default: nomad-lakehouse)

Changes require restarting services via docker compose down && docker compose up -d to take effect.
